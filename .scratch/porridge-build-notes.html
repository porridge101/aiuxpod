AI UX Porridge

How a five-minute daily podcast about AI & product design gets made, end to end, with no one at the keyboard.

Solo build Python 3.12 $0/mo infra

01 What it is

A fully automated daily podcast: a 1–2 minute audio briefing on AI and product design news, plus a companion email digest, delivered every weekday morning before 5am AEST. No manual step in the loop — it fetches, writes, voices, and publishes itself.

It ships as a real podcast RSS feed (subscribed in Pocket Casts) hosted on GitHub Pages, with the source feeds, the script, and the audio all regenerated fresh each morning.

02 The process

  1. Wrote the brief before writing code

    Locked in the goal, the stack, the sources, and the acceptance criteria in a short doc first — including the constraint that it had to run for close to $0/month. That doc is the spec I kept building back against.

  2. Built it local-first

    Got one command producing a listenable MP3 from real feed items before touching any automation. Iterated on the Claude prompt (tone, length, story selection) and the TTS voice entirely by ear at this stage.

  3. Wrapped it in automation

    Moved the working pipeline into a scheduled GitHub Actions workflow. Made it fail loudly on a broken run rather than silently publish a bad or empty episode, and skip publishing outright on a genuinely quiet news day.

  4. Tuned it by listening

    Kept refining post-launch from actually hearing the episodes: narrowed noisy sources, tightened joke length, added a pun to the opening, and rotated the host voice across accents so it doesn't sound like the same person every day.

04 The pipeline, in order

  1. 1
    Fetch
    Pull items from the last 24h across all RSS sources, plus scrape three newsletters that have no feed
  2. 2
    Extract
    Fetch full article text for any item whose feed content is just a short excerpt
  3. 3
    Dedupe
    Cluster near-identical headlines across sources, keep the most detailed version
  4. 4
    Garnish
    Fetch today's national/world day and a candidate joke from Reddit — both optional
  5. 5
    Summarise
    Claude picks the top stories, writes the spoken script, and drafts the email digest in one structured call
  6. 6
    Voice
    Synthesise the script to MP3 with the day's rotated voice
  7. 7
    Publish
    Append the episode to feed.xml, prune anything past the 30-episode retention window, commit and push
  8. 8
    Notify
    Email the digest with the audio link, story summaries, and toolkit updates

05 Decisions worth explaining

Fail loud vs. fail soft

Core sources failing is an error; garnish failing isn't. If every news source fails, the run stops rather than publishing an empty episode. If the joke or national-day fetch fails, the episode just publishes without them.

Quiet days skip, they don't pad

No new items in 24h means no episode that day, rather than stretching thin news into a full script.

Deterministic voice rotation

The daily voice is picked by hashing the date, not randomly — so re-running the same day's episode always gets the same voice, but different days land on different accents.

Retention cap

Only the latest 30 episodes are kept, older MP3s and feed entries are pruned automatically, keeping the repo (and Pages hosting) small forever.
